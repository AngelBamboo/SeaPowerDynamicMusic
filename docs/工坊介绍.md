# 自定义动态音乐

让 Sea Power 的背景音乐跟随游戏状态自动切换。曲库默认调用游戏自带的 22 首官方音乐，也可以添加你自己喜欢的曲子。

## 安装

本模组依赖 [Anchor Chain](https://steamcommunity.com/sharedfiles/filedetails/?id=3380210757)（社区模组加载器）。订阅本模组前请先装好它。

Anchor Chain 的安装需要两个动作，顺序不能反：

1. 从 [GitHub Releases](https://github.com/SeaPower-Modders/AnchorChain/releases) 下载最新的 `ACPreloader.zip`，解压到游戏根目录（与 `Sea Power.exe` 同级的目录）。解压后应能看到 `BepInEx`、`winhttp.dll`、`doorstop_config.ini` 三项。
2. 进游戏跑一次，让 BepInEx 生成配置文件。
3. 到工坊订阅 Anchor Chain。

完成后订阅本模组即可，无需其他操作。

## 添加自定义音乐

在游戏根目录的 `Sea Power_Data` 下新建一个名为 `MusicLibrary` 的文件夹，再按场景建立子目录：

```
Sea Power\
  MusicLibrary\
    MainMenu\        主菜单
    StrategicMap\    战略地图、战役界面
    Nato\            北约
    WP\              华约
    Night\           夜间
    Victory\         任务胜利
    Defeat\          任务失败
```

目录名也认中文：`主菜单`、`战略地图`、`北约`、`华约`、`夜间`或`夜晚`、`胜利`、`失败`。

**支持的格式**：`.mp3`、`.ogg`、`.wav`、`.aiff`、`.aif`。推荐 ogg 或 mp3，体积小、音质损失小。

直接放在 `MusicLibrary` 根目录下的曲子也能被识别，但不参与播放，面板里归在「未归类」，需要手动勾选归属。

放完不用重启游戏，按 F7 打开面板点「重新扫描」即可。

## 面板用法

启动游戏后按 **F7** 打开管理面板。面板分三列，从左到右逐级收窄：

| 列 | 内容 |
|---|---|
| 第一列 | 大类：界面音乐、战役音乐、结算音乐 |
| 第二列 | 场景：主菜单、战略地图，或北约、华约、夜间，或胜利、失败 |
| 第三列 | 该场景下的所有曲目 |

第三列每行的操作：

| 操作 | 作用 |
|---|---|
| 点曲名 | 试听 |
| 勾选框 | 启用或停用这首曲子 |
| 权重 0~3 | 被抽中的概率，越大越容易选中。0 表示不参与 |
| 优先 0~5 | 数字越大越优先。只在最高优先级里挑，这一档播完才降档 |
| 归属分类 | 勾选这首曲子出现在哪几个场景，可以同时属于多个 |

**「按权重随机」**（面板左下角）决定多首候选时如何选择：

- **开启**：按各自权重随机抽取，权重都设为 1.0 即等概率
- **关闭**：按列表顺序循环，此时权重不再起作用

改完点「保存」。「重新扫描」会先自动保存再重新读取。

## 功能

- **跟随游戏状态。** 监听游戏自身的场景切换信号，界面变了音乐跟着变，无需手动操作
- **官方音乐直接可用。** 面板中带 `[官方]` 标记，复用游戏已加载的音频，不复制文件也不额外占内存
- **一首曲子可用于多个分类。** 在归属里勾选即可
- **权重与优先级。** 权重决定被抽中的概率，优先级决定播放顺序，同档播完一轮才降档
- **不会重复播放同一首。** 正在播放的那首不参与下一次挑选
- **缺曲目自动退让。** 华约没曲子就用北约顶上，不会突然静默
- **官方音乐兜底。** 某场景下没有自备曲目时自动改播对应的官方音乐
- **一键切回原版模式。** 随时交还给游戏
- **中英文界面。** 左上角切换，默认跟随游戏语言设置
- **跨场景淡入淡出。** 切歌不会突然断掉

## 已知问题

- **鼠标点击会穿透到游戏。** 点击面板按钮时事件有时会同时被游戏接收，在战斗中表现为点面板的同时也点到了目标或指令。暂无可行的规避办法，建议在菜单界面下使用面板
- **切换原版模式偶尔不生效。** 进入时游戏音乐有时不会立刻停下，退出时模组音乐也没有马上接回，重新按一次通常恢复
- **本模组不含音乐文件。** 订阅后曲库只有官方音乐，需要自己添加，或订阅配套的音乐扩展包
- **战况切换延迟为设计如此。** 发现敌情后 3 秒才切换，脱离交战 25 秒后才切回，避免一点动静就跳曲。数值可在配置文件中修改
