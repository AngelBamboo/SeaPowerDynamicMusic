# 自定义动态音乐

让《Sea Power : Naval Combat in the Missile Age》的背景音乐跟着游戏状态走。放在主菜单是安静的底乐，
进了战役就换成紧张的音乐，任务结算再切回舒缓的段落。曲库用你自己的文件，
官方那 22 首也能直接调进来用。

## 安装

### 第一步：装 Anchor Chain

本模组依赖社区的模组加载器 Anchor Chain。分两个动作，顺序不能反：

1. 从 [GitHub Releases](https://github.com/SeaPower-Modders/AnchorChain/releases)
   下载最新的 `ACPreloader.zip`，解压到游戏根目录（与 `Sea Power.exe` 同级的目录）。
   解压后应该能看到 `BepInEx`、`winhttp.dll`、`doorstop_config.ini` 三项。
2. 进游戏跑一次，让 BepInEx 生成配置文件。
3. 到工坊订阅 [Anchor Chain](https://steamcommunity.com/sharedfiles/filedetails/?id=3380210757)。

### 第二步：装本模组

到工坊订阅即可，无需其他操作。

### 不想用工坊的话

把 `SeaPowerDynamicMusic` 整个文件夹放进
`Sea Power_Data\StreamingAssets\`，然后确保 Anchor Chain 已装好。
只把 `SeaPowerDynamicMusic.dll` 放进 `BepInEx\plugins\` 也能用，
它带独立的 BepInEx 入口，不依赖 Anchor Chain 的配置管理。

## 增加自定义音乐

找到游戏根目录`Sea Power_Data`下，新建一个名为`MusicLibrary` 文件夹。
在这个文件夹下可以分别新建各自场景的文件夹（MainMenu、StrategicMap、Nato、WP、Night、Victory、Defeat）
把自己喜欢的音乐可以简单分类放进子目录：

```
Sea Power\
  MusicLibrary\
    MainMenu\        主菜单
    StrategicMap\    战略地图、战役界面
    Nato\            北约
    WP\              华约
    Night\           夜间
    Victory\         任务胜利
    Defeat\          任务失败
```

目录名也认中文：`主菜单`、`战略地图`、`北约`、`华约`、`夜间`或`夜晚`、`胜利`、`失败`。

**支持的格式**：`.mp3`、`.ogg`、`.wav`、`.aiff`、`.aif`。推荐 ogg 或 mp3，体积小、音质损失小。

直接把音频丢在 `MusicLibrary` 根目录下（不进子目录）也能识别，
但这类曲子不参与播放，面板里归在「未归类」，需要你手动勾选归属。

**放完不用重启游戏**，按 F7 打开面板点「重新扫描」就行。

## 用法

启动游戏后按 **F7** 打开管理面板。

面板分三列，从左到右逐级收窄：

| 列 | 内容 |
|---|---|
| 第一列 | 大类：界面音乐、战役音乐、结算音乐 |
| 第二列 | 场景：主菜单、战略地图，或北约、华约、夜间，或胜利、失败 |
| 第三列 | 该场景下的所有曲目 |

第三列每行可以做的事：

| 操作 | 作用 |
|---|---|
| 点曲名 | 试听 |
| 勾选框 | 启用或停用这首曲子 |
| 权重 0~3 | 被抽中的概率，越大越容易选中。0 表示不参与 |
| 优先 0~5 | 数字越大越优先。只在最高优先级里挑，这一档全部播完才降档 |
| 归属分类 | 勾选这首曲子出现在哪几个场景里，可以同时属于多个 |

**「按权重随机」**（面板左下角）决定多首候选时怎么选：

- **开启**：按各自的权重随机抽。权重都设成 1.0 就是等概率
- **关闭**：按列表顺序循环，这时权重不再起作用

改完点「保存」。「重新扫描」会先自动保存再重新读取。

## 功能

**跟随游戏状态。** 监听游戏自己的场景切换信号，界面变了音乐跟着变，不需要手动切换。

**官方音乐直接可用。** 面板里带 `[官方]` 标记的就是游戏自带曲目，复用游戏已经加载的音频对象，不复制文件也不额外占内存。共 22 首，覆盖界面、战役与结算。

**一首歌可用于多个分类。** 同一首曲子可以同时归入「北约」和「夜间」，在归属里勾选即可。

**权重与优先级。** 权重决定被抽中的概率，优先级决定播放顺序。同一档里每首播完一轮才降到下一档。

**不会重复播同一首。** 正在播放的那首不参与下一次挑选。

**缺曲目自动退让。** 华约没曲子就用北约顶上，界面没曲子就用战役的，不会突然静默。

**官方音乐兜底。** 某场景下你自己没放曲子时，会自动改播对应的官方音乐。

**一键切回原版。** 面板里点「原版模式」完全交还给游戏，随时能切回来。

**中英文界面。** 左上角切换，首次打开跟随游戏语言设置。

**跨场景淡入淡出。** 用两个音源做交叉淡化，切歌不会突然断掉。

## 已知问题

**鼠标点击会穿透到游戏。** 面板上的按钮按下时，点击事件有时会同时被游戏接收，
在战斗中选择目标或触发指令会发现鼠标在面板上也点了一下。暂时没找到可靠的规避办法，
如果你介意这个问题，建议在菜单界面下面再打开面板。

**切换原版模式偶尔不生效。** 点「原版模式」后游戏音乐有时不会立刻停下，
或者从原版模式退出后模组音乐没有马上接回来。重新按一次通常就好了。

**工坊音乐包需要自己装。** 本模组不含任何音乐文件。订阅扩展包之后，
包里的音乐会出现在面板中，和你自己放的音乐一起参与播放。

**战况切换有延迟是设计如此。** 发现敌情后等 3 秒才切紧张音乐，脱离交战后等 25 秒才切回来，
防止一点动静就跳曲、或者刚脱离战斗又被打断。数值可以在配置文件里改。
