Sea Power Dynamic Music / 动态音乐系统
======================================

前置要求
--------
本模组依赖 Anchor Chain 链式加载器。如果你的模组列表里没有 Anchor Chain，
请先按它的说明安装（需要先从 GitHub 下载 ACPreloader 解压到游戏根目录）。
没有 Anchor Chain 时本模组不会加载。

首次使用
--------
1. 启动游戏一次。Anchor Chain 会自动生成本模组的配置文件
2. 把音乐文件（mp3 / ogg / wav）放进对应分类的子文件夹
3. 按 F7 打开管理面板，点「重新扫描」，不需要重启游戏

管理面板：三级菜单
------------------
面板左侧分三列，从左到右逐级收窄：

  第一列  大类      界面音乐 / 战役音乐 / 结算音乐
  第二列  场景      主菜单、战略地图 / 平静巡航、发现敌情、交战 / 胜利、失败 / 未归类
  第三列  曲目      该场景下的所有曲子

第三列每行可以做的事：

  点曲名        试听
  勾选框        启用或停用这首曲子
  权重 0~3      被随机抽中的概率，越大越容易选中。0 表示不参与
  优先 0~5      数字越大越优先。只在最高优先级里挑，这一档全部播完才降档
  归属分类      勾选这首曲子出现在哪几个场景里，可以同时属于多个

改完记得点「保存」。「重新扫描」会先自动保存再重新读取。

游戏自带音乐
------------
面板里带 [官方] 前缀的是游戏自带音乐，一共 7 首左右。
这些曲子直接复用游戏已经加载好的音频，不会额外占用内存。

官方音乐默认参与随机，底部可以关掉「含官方音乐」，关掉后只播你自己放的曲子。

官方的战役音乐（nato、wp、night）同时归入平静巡航、发现敌情、交战三个场景，
所以你在交战场景下也能看到它们，并且可以单独调整权重或取消某个场景的归属。

目录结构
--------
Sea Power\
  MusicLibrary\
    MainMenu\        主菜单
    StrategicMap\    战略地图、战役界面
    Cruise\          平静巡航
    Tension\         发现敌情，尚未开火
    Combat\          交战
    Victory\         任务胜利
    Defeat\          任务失败
    Credits\         制作人员名单

也支持中文文件夹名：巡航、紧张、交战、胜利、失败、主菜单、战略地图。

没放进任何分类目录的曲子会归到「未归类」，只是不播放，在面板里仍能看到并调整归属。

不想挪动文件的话，可以在配置文件里写路径：

  [Combat]
  Track01=D:\Music\battle_theme.mp3
  Track02=D:\Music\tense_01.ogg

注意曲目必须写成 Track01=路径 这种带等号的形式，
只写一行路径而不带等号，Anchor Chain 回写配置时会把它丢掉。

配置文件位置
------------
Sea Power_Data\StreamingAssets\ACConfigs\io.github.angelbamboo.dynamicmusic_user.ini

这是 Anchor Chain 管理的用户配置。模组更新时只会补齐新增的选项，
不会覆盖你改过的内容。模组目录里的 io.github.angelbamboo.dynamicmusic.ini
是参考默认值，通常不需要动。

配置里的 [Tracks] 段由模组自动维护，记录每首曲子的归属分类、权重与优先级，
格式为：

  T1A2B3C4D=Combat,MainMenu|1.5|2|0|D:\Music\battle.mp3

依次是：键、分类列表（逗号分隔）、权重、优先级、是否停用、文件路径。
这一段不建议手工编辑，界面上的改动会覆盖它。

分类缺失时的行为
----------------
某个分类下没有可用曲目时不会静音，而是逐级退让：

  交战 -> 紧张 -> 巡航

只准备了几首巡航音乐也能正常使用。胜利和失败没有可用曲目时保持当前播放，
不会突兀换歌。

支持的格式
----------
mp3、ogg、wav、aiff。推荐 ogg 或 mp3。

排查问题
--------
日志在 BepInEx\LogOutput.log。搜索「Dynamic Music」就能找到本模组的记录，
包括扫描到多少首、导入多少首官方音乐、哪些文件加载失败。

常见情况：
  - 面板显示 0 首：确认音乐放在 MusicLibrary 的子文件夹里，而不是直接丢在根目录
  - 没看到 [官方] 音乐：日志里搜「官方音乐」，可能是游戏还没加载完，
    稍后点一次「重新扫描」即可
  - 某个文件显示「失败」：该文件的编码可能不受支持，转成 ogg 通常能解决
  - 完全没有声音：先确认游戏原生音乐是否正常，再看日志里有没有加载记录
  - 改完不生效：面板改动需要点「保存」才会写入配置
  - 模组列表里没有本模组：多半是 Anchor Chain 没装或没订阅
